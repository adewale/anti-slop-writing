# Changelog

All notable changes to this project are recorded here. This changelog tracks doctrine, eval coverage, compatibility, and docs because a skill can change behavior without changing code.

## [Unreleased]

### Doctrine

- Added new-register (2025+) coverage after diffing Simon Willison's [llm-cliche-highlighter](https://github.com/simonw/tools/blob/main/llm-cliche-highlighter.html) (simonw/tools, Apache-2.0) against the doctrine: all 27 of its conversational-register patterns were absent. `SKILL.md` gains two detector entries — the five phrase families (significance compression, therapy voice, performative honesty, stage management, dev-blog boilerplate) with dose-response framing ("one hit can be voice; several in one passage is the tell"), and six structural cadence shapes (negation/did-not chains, sentence anaphora, stacked questions, echo skeletons, stranded auxiliaries) with an earned-use boundary ("keep repetition only when each item is independently checkable or adds a link in a real chain") — plus nine avoid-phrases, five high-risk words from the highlighter's Wikipedia group (`interplay`, `vibrant`, `bustling`, `commendable`, `ever-evolving`), and a drift-note extension. Net +197 words against the +200/round budget after consolidating the two `Not just/only X` banned-phrase near-duplicates. Long-form family descriptions, the four earned-use keep examples, and provenance live in `references/anti-slop-writing-doctrine.md` → "New-register tells and structural cadence"; two rewrite moves (fact extraction, cadence-to-findings resolution) in `references/rewrite-patterns.md`.
- Added a `Parataxis and hypotaxis` teaching section to `references/anti-slop-writing-doctrine.md` and a flow-by-relation diagnosis bullet. This names the concept and consolidates existing guidance (the staccato "keep or use once" rule and the symmetrical-structure tell); it is a reference-only addition and does not change gated `SKILL.md` behavior. A stronger `SKILL.md` rule was tried and reverted (see Evals / `evals/rejected-edits.md`).
- Added detectors for copula displacement, hedged symmetry, outline-shaped conclusions, and decorative em-dash clusters. The rules include earned-use boundaries: `serves` can introduce a concrete enumeration, `Whether X or Y` can name a real branching condition, and em-dash pairs can bracket an inline definition.
- Added a time-dated-word-list note: high-risk word lists should be re-profiled against current human-vs-LLM corpora; do not invent precise drift percentages when the source only supports a qualitative claim.
- Added two procedural detectors to `skills/anti-slop-writing/SKILL.md`: the **emphasis-source test** (write the flattened version of the line in the critique; judge whether the residual claim still names actor/mechanism/limit) and the **syntax-relation test** (restate the implied relation with a connective; if no connective fits without invention, the syntax was empty). Sourced from Ruth Starkman, "Model Style Is So Cringe." Retained on qualitative behavioral evidence: under the blinded harness the procedural wording reliably produces the flatten artifact in critique text while the labeled wording does not. The +1 score delta from the worked Round 5 does not pass `scripts/score_delta.py` at N=5 (CI overlaps zero, sign-flip p=1.0); recorded honestly in `evals/results/2026-05-27-emphasis-source-experiment.md` and the gate output in `evals/results/2026-05-28-emphasis-source-procedural/`.

### Deterministic graders

- Added `evals/oracles/slop_lint.py`: a deterministic slop-lint oracle porting 22 detectors from the llm-cliche-highlighter (Apache-2.0, attributed in the module docstring) — six structural finders with chain-item counting, the five new-register families, and eleven Wikipedia-register detectors including `chatbot-leftovers` (oaicite/contentReference/utm_source debris). Dose-response severity (`ai-vocabulary` is soft, threshold 2), ~130 embedded positive **and negative** self-test cases, and a demo fixture (`evals/fixtures/slop-lint-demo/input.md`) engineered to trip every detector exactly once — the highlighter's self-testing design, kept. Three noisy detectors deliberately not ported (`colon-triple`, `dont-verb-it`, `is-real`); rationale in `docs/deterministic-graders.md`.
- Eval cases can now carry a `deterministic_checks` block (forbid/require detector checks and format-regex checks, with `scope: "rewrite"` to lint only the last `Concrete rewrite:` block so critiques can quote the tells they flag). `scripts/run_evals.py` gains a `lint` subcommand that grades these blocks mechanically — no sub-agent, no judge bias, zero token cost — emitting judgment-shaped rows that `grade` merges with judge rows per case id. `scripts/validate.py` validates check shapes against the oracle registry and runs the oracle self-tests on every validation; `docs/judge-protocol.md` documents the new Phase 2.5. Design rules (forbid-shaped checks, hit-is-a-hypothesis) in `docs/deterministic-graders.md`. This narrows the judge surface while the cross-family-judge `TODO.md` item stays open for the assertions only a judge can grade.
- Added thirteen eval cases for the new register, each carrying `source` provenance and (where the assertion is mechanical) `deterministic_checks`: `evals/evals.json` → `new-register-significance-compression`, `performative-honesty-stage-management`, `structural-cadence-run` (tune), `holdout-devblog-boilerplate`, `holdout-therapy-voice-retro` (holdout); `evals/adversarial.json` → `earned-negation-chain-changelog`, `earned-turns-out-with-trace`, `earned-anaphora-invariant-chain` (tune), `holdout-earned-honesty-clarification` (holdout) — the earned-use guards pinning that oracle hits are hypotheses, not verdicts; `evals/rewrite-evals.json` → `strip-new-register-launch` (tune), `holdout-stage-managed-postmortem` (holdout); `evals/meta-evals.json` → `deterministic-vs-judge-split` (tune), `holdout-oracle-drift-review` (holdout). Plus manual cases 11-12 in `evals/cases.md`, `evals/failures/new-register-conversational-slop.md`, and `examples/cards/new-register-launch-copy.md`. Deterministic smoke run recorded in `evals/results/2026-08-29-highlighter-mining.md`.

### Evals

- Ran a stop-slop idea ablation (`evals/results/2026-06-14-stop-slop-ablation/`). Reviewed the sibling skill [hardikpandya/stop-slop](https://github.com/hardikpandya/stop-slop) and A/B-tested two borrowed ideas — a 5-axis 1-10 self-score gate (`< 35/50 -> revise`) and a "cut quotables" detector, both adapted with mechanism-aware guards rather than stop-slop's literal blanket bans — against a baseline snapshot across three models (Opus 4.8, Sonnet 4.6, Haiku 4.5), apply/judge separated. Round 1 (six tune cases, binary): all 18 paired deltas exactly 0.00. Round 2 (six fresh holdout cases with 1-5 graded dimensions, `round2-holdout-graded.json`): graded scores showed real spread (Opus 0.87 / 0.93, not ceiling), yet all 18 paired graded deltas were again exactly 0.00 (`scripts/score_delta.py`: mean +0.0000, CI [0,0], p=1.0 — REJECT). "Cut quotables" is the emphasis-source test we already ship, and the self-score gate is a numeric reskin of the existing bounded judge-refine pass. Not added to `SKILL.md`; logged in `evals/rejected-edits.md` and `Lessons_learned.md`.
- Added `docs/eval-null-result-literature.md`: a cited methodology note on how to read a null/zero eval delta — a failed superiority test (`score_delta.py` REJECT) is not proof of no effect; the explicit "it does nothing" claim needs an equivalence test (TOST) against a stated SESOI. Covers small-N non-CLT intervals (Bowyer et al., ICML 2025, arXiv 2503.01747), paired question-level analysis (Miller, arXiv 2411.00640), ceiling/saturation and IRT difficulty calibration (arXiv 2505.15055, 2602.16763), and LLM-as-judge bias as the binding risk on a single-family judge — which reinforces the existing cross-family-judge `TODO.md` item.
- Added `evals/adversarial.json` → `earned-passive-adverb-when-opener` (tune): a regression guard against the blanket-ban failure mode the stop-slop rules would introduce if copied literally. It pins "keep earned passive voice, an earned adverb, and a subordinate `When ...` opener" when each token is backed by a named mechanism (lease expiry, automatic requeue, unreachable worker).

### Hillclimb infrastructure

- Promoted three stop-slop-derived cases into the live suites: `evals/adversarial.json` → `stopslop-divergence-no-mechanism-closer`, `stopslop-divergence-compressed-antithesis` (holdout); `evals/rewrite-evals.json` → `stopslop-thin-content-cut-or-ask` (holdout). - Added a cross-family judge panel run that hardens the stop-slop ablation null: 15/18 A/B output pairs were byte-identical (judge-invariant); the 3 differing pairs were re-judged by all three model families and every judge returned A=B (EQUIVALENT at SESOI ±0.05). The "no effect" no longer depends on single-family (Opus) judging — the standing item from `docs/eval-null-result-literature.md` §5.
- Added `scripts/saturation_index.py`: groups a `run_evals.py grade` scores file by case across the varied axis (models/judges) and reports per-case spread plus an overall saturation index, flagging CEILING cases where a zero delta is only no-regression evidence. On the round-2 graded scores it shows 4/6 cases still at ceiling (index 0.667), i.e. round 2 only partially de-saturated the suite.
- Added a Pre-registration step to `runbooks/hillclimb-skill.md`: declare SESOI, N/axes, and the judge panel before scoring (Miller, arXiv 2411.00640); report a null round as a TOST equivalence result via `score_delta.py --sesoi`, and run `saturation_index.py` before trusting any zero delta.
- Added a TOST equivalence mode to `scripts/score_delta.py` (`--sesoi S`). The default gate is a superiority test, whose REJECT means "no improvement detected", not "no effect"; with a declared smallest-effect-of-interest it now also reports whether the `(1 - 2*alpha)` CI on the delta lies within `(-S, +S)`, licensing an explicit equivalence claim. Motivated by the 2026-06-14 stop-slop ablation, which returns EQUIVALENT at SESOI ±0.05. Backed by `docs/eval-null-result-literature.md`.

### Doctrine

- Added a final self-check and one bounded judge-refine pass for high-stakes prose.
- Extended the Final self-check to require running the same detectors on the rewrite and to require asking or cutting when a rewrite would need a fact not present in the source.
- Added `ask-author` as a verdict in the Critique output format, with a triggering rule in the Default editing pass: do not invent a tool, person, count, or timing to fill the Concrete rewrite slot when the source paragraph does not supply it.
- Tightened the antithesis classification rule: read the prior sentence in the paragraph before grading contrast as compressed or decorative. Anchored on a real failure from joe.dev/posts/thinking-out-loud where the skill graded earned contrast as decorative because it scored the sentence alone.
- Added a mandatory `Rewrite check` field to the Critique output format so the same detectors run against every Concrete rewrite (including ask-author fallbacks) inside the per-item loop, not at end-of-document. Added a "Rewrites must pass the same detectors as the source" section to `references/rewrite-patterns.md` with real before/after pairs from the joe.dev review.
- Clarified the Staccato contrast test in `SKILL.md` with the both-sides test: an antithesis is earned only when both sides of the contrast are evidenced in the prior prose, not when only the topic of the contrast was mentioned. Carries the joe.dev pair as the canonical compressed example. Corrected the eval assertion and failure-file claims that previously framed the model's compressed verdict on `That's not incidental. It's the design.` as a misclassification.
