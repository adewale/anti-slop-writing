We rebuilt the editor, and we made it small on purpose. Staying small costs features; we accepted that to get a tool that does few enough things that one person can learn all of them.

The way in shows the same subtraction: you reach a cursor without creating an account, downloading anything, or setting a single option, and the first key you press lands in the text. If you want to check that, open the editor and count what it asks of you before you can type. We rebuilt it so the answer is nothing.
