Zero hits on one detector and a rising count on another across the same fifty runs are not two facts to average — they're one fact seen from two elevations. Reading the detector names against the doctrine's own structure: "ai-vocabulary" is almost certainly the literal word-and-phrase lists, the "Avoid by default" templates and the "Words to review" terms like "delve," "testament," "pivotal" — a check that can only fire when an exact string shows up. "Significance-compression" reads as the structural detector for the doctrine's core principle itself: prose that claims importance without the detail to earn it, the "less detail, more importance" antipattern, closer in shape to the compressed-antithesis pattern — one side of a claim evidenced, the other asserted on rhythm alone — than to any single word. That distinction is most of the answer: one detector watches vocabulary, the other watches a relationship between a claim and its support, and only the first can go stale just from the model changing its word choices.

A flatlined vocabulary detector across fifty runs does not mean the model stopped writing slop; the rising second number already rules that reading out. What it means is that the current generation's surface vocabulary has moved off the specific strings on the list. That is the exact drift the doctrine names outright when it calls "delve" "the cautionary example of a high-risk word whose frequency in LLM output dropped sharply during 2025," in the same breath instructing you to "re-profile against a current human-vs-LLM corpus before adding or removing entries." Fifty consecutive zero-hit runs on a list profiled against an older corpus is not a clean bill of health; it is the re-profile trigger firing. One thing worth ruling out first: whether the corpus being linted changed shape over those fifty runs — shorter outputs, a different domain, more code — since that would produce the same zero count for a reason that has nothing to do with model drift. Absent that confound, the doctrine already predicted this exact result and already named the fix.

The fix is not to sharpen the vocabulary list, because sharpening a list that has already gone quiet is chasing a signal that already left. Re-profile it against current output, expect to retire entries the way "delve" itself was flagged as declining, and stop reading a zero from that detector as evidence the prose is clean. That last point should change how the harness reports the two numbers: if a dashboard averages both detectors into one slop score, the flat vocabulary line will visually cancel the rising compression line, understating a regression the run history is actually showing. Report them separately, or the quiet detector will manufacture reassurance the data does not support.

For the doctrine, the pattern is confirmation rather than a surprise, and it validates the order the doctrine already put things in. The core principle sits above the word lists for exactly this reason: "sharp detail beats inflated significance" describes a relationship between a claim and its evidence, which survives a model changing its vocabulary, while a word list only describes one generation's habits. Rising significance-compression hits next to a dead vocabulary detector say that models are still inflating significance, just through structure now — copula displacement, hedged symmetry, an antithesis whose second half was never earned — instead of through the specific words a 2023-2024 corpus happened to associate with it. The doctrine built detectors for that shift before this run history proved they were needed; the fifty-run pattern is the evidence to act on the imbalance, not a reason to invent a new principle. Re-profile the words. Leave the weight on the detector that is still finding the real failure.
